# 報名表 PDF 自動存入雲端硬碟：設定步驟

各校按「完成報名」或「更新報名」時，系統會把無核章欄 PDF 上傳到主辦單位的 Google 雲端硬碟，檔名為「縣市_校名_報名表.pdf」，例如 `臺北市_光復國小_報名表.pdf`。同一所學校再次更新時，新檔會取代舊檔，舊檔會移到垃圾桶。

## 1. 建立雲端硬碟資料夾
1. 在 Google 雲端硬碟新增一個資料夾，例如「2027立德盃報名表」。
2. 打開這個資料夾，複製網址列 `folders/` 後面那串文字，這就是資料夾 ID。

## 2. 建立 Apps Script
1. 前往 https://script.google.com ，點「新專案」。
2. 刪除編輯器裡原有的程式碼，貼上 `apps-script/Code.gs` 的全部內容。
3. 把第 6 行的 `請貼上雲端硬碟資料夾ID` 換成步驟 1 複製的 ID，然後按儲存。

## 3. 部署成網頁應用程式
1. 點右上角「部署」→「新增部署作業」→ 齒輪圖示選「網頁應用程式」。
2. 「執行身分」選「我」，「誰可以存取」選「所有人」。
3. 按「部署」，依照畫面授權存取你的雲端硬碟。
4. 複製產生的網址（`https://script.google.com/macros/s/.../exec`）。

## 4. 填入報名表
把步驟 3 的網址填進 `index.html` 裡的 `const UPLOAD_URL='';` 引號中間。

## 注意事項
- 各校的聯絡人姓名、行動電話、Email 和上傳時間，會寫在雲端硬碟檔案的「說明」欄位，在檔案的「詳細資料」中可以看到。
- 這個上傳網址不需要登入，任何人都能上傳；有人用同一個縣市和校名送出時，會覆蓋原本的檔案。被取代的舊檔留在垃圾桶裡，30 天內都可以還原。
- 修改 Code.gs 後要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」，修改才會生效。
